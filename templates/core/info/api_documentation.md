# Order API & Webhooks Documentation

This document describes how to integrate with the Cholbe AI Order API and secure incoming Webhook deliveries.

---

## Authentication

All API requests must include the `X-API-Key` header with your business profile's API key.

> [!IMPORTANT]
> Keep your API key secret. Do not expose it in client-side code (e.g. frontend browsers).
> API keys automatically generated by Cholbe AI start with the `bkai_` prefix. Disabling API access in the dashboard will revoke and clear the API key.

**Example Request Header:**
```http
X-API-Key: bkai_9f1a2b3c4d5e6f7a8b9c0d1e2f...
Content-Type: application/json
```

## Order API (Read-Only)

### 1. List Orders
Retrieve a list of orders for the authenticated business profile. Orders are returned in reverse chronological order (newest first).

* **URL:** `/business-profile/api/orders/`
* **Method:** `GET`
* **Headers:** `X-API-Key` (Required)

#### Query Filters
You can filter returned orders using the following optional query parameters:

| Parameter | Type | Description |
| :--- | :--- | :--- |
| `created_at__gte` | String (ISO Datetime) | Filter orders created on or after this timestamp (e.g., `2026-06-01T00:00:00`). |
| `created_at__lte` | String (ISO Datetime) | Filter orders created on or before this timestamp (e.g., `2026-06-07T23:59:59`). |
| `q` | String | Search for a substring across the order's custom fields dictionary. |

**Example Filter URL:**
`GET /business-profile/api/orders/?q=01711&created_at__gte=2026-06-01`

## Webhooks

When an order is created or updated in the system (e.g., via the AI chat agent), an HTTP POST request is triggered asynchronously to your configured **Webhook URL**.

### Webhook Payload
The webhook POST request contains the Order details directly at the root level.

```json
{
  "id": 12,
  "customer": {
    "id": 8,
    "name": "John Doe",
    "platform": "facebook",
    "platform_id": "234342342387234",
    "profile_pic": "https://cholbeai.com/media/profile_pic/john_doe.jpg"
  },
  "conversation_id": 4,
  "fields": {
    "name": "John Doe",
    "phone": "01711223344",
    "address": "Dhaka, Bangladesh"
  },
  "created_at": "2026-06-06T15:58:10.123456+06:00",
  "updated_at": "2026-06-06T15:58:10.123456+06:00"
}
```

### Signature Verification (Security)
To verify that the webhook request originated from Cholbe AI, each request contains signature headers:

* `X-SAE-Signature`
* `X-Signature`

These headers contain the HMAC-SHA256 signature of the raw request body payload, using your business profile's **API key** as the shared secret key.

> [!TIP]
> Always verify this signature on your server before processing the order payload to prevent spoofing.

#### Example Verification (Python)
```python
import hmac
import hashlib

def verify_webhook(request_body_bytes, api_key, signature_header):
    computed = hmac.new(
        api_key.encode('utf-8'),
        request_body_bytes,
        hashlib.sha256
    ).hexdigest()
    
    return hmac.compare_digest(computed, signature_header)
```
